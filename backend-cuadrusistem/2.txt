 Aquí tienes la hoja de ruta definitiva para el despliegue:

  1. Plataforma Recomendada: Railway (Todo en uno)
  Aunque podrías usar Vercel para el frontend, te recomiendo Railway para ambos para mantener la "simbiósis" que mencionabas en un solo panel de control.

  Paso A: La Base de Datos (PostgreSQL)
   1. En Railway, dale a "New" -> "Database" -> "Add PostgreSQL".
   2. Esto te generará una base de datos vacía.
   3. Importante: Debes ejecutar el archivo backend-cuadrusistem/schema.sql en esta base de datos. Puedes hacerlo desde la pestaña "Query" de Railway o conectándote con un cliente como DBeaver o pgAdmin.

  Paso B: El Backend (Servicio 1)
   1. "New" -> "GitHub Repo" -> Selecciona tu repositorio.
   2. En la configuración del servicio (Settings):
       * Root Directory: backend-cuadrusistem
       * Build Command: npm run build
       * Start Command: npm start
   3. Variables de Entorno: Railway detectará el Dockerfile que creamos y lo usará. Debes copiar las variables de PostgreSQL que Railway te dio a este servicio (DB_HOST, DB_USER, etc.).

  Paso C: El Frontend (Servicio 2)
   1. "New" -> "GitHub Repo" -> Selecciona el mismo repositorio.
   2. En la configuración del servicio (Settings):
       * Root Directory: frontend-cuadrusistem
       * Build Command: npm run build
       * Start Command: npm run preview (o dejar que Railway detecte Vite automáticamente).
   3. Variable Vital: Crea la variable VITE_API_BASE_URL y ponle la URL pública que Railway le asigne a tu Backend (ej: https://backend-production-xyz.up.railway.app/api).

  2. Checklist de Conectividad
  Para que todo fluya sin problemas:
   * [ ] CORS: En el panel de Railway del Backend, asegúrate de añadir la URL del Frontend en la variable CORS_ORIGIN. Esto permite que el navegador acepte las peticiones.
   * [ ] SSL: Railway te da HTTPS automáticamente, lo cual es vital para que los teléfonos Apple y Android permitan subir fotos desde la cámara.

  3. Consideración del Monorepo
  Como no tienes un package.json en la raíz (son dos carpetas independientes), Railway te preguntará qué carpeta quieres desplegar al añadir el repo. Solo tienes que repetir el proceso de "New Service" dos veces,
  eligiendo una carpeta distinta cada vez.
